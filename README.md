# RIO Australia

Marketing site for RIO Australia, a commercial cleaning business in south-east Melbourne. It's built with Next.js (static export), React Three Fiber, Motion and Lenis, and hosted on GitHub Pages.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in ./out
npm run lint
```

All copy lives in `src/content/site.ts`. See `CLAUDE.md` for the business rules, honesty rules and 3D guidelines.
